# Работа со статическими мокапами

Храни оригиналы и их историю в `apps/mockups/public/legacy/`, рядом с Angular-приложением в `apps/mockups/src/`. После переноса в Angular оригиналы остаются в архиве. Не создавай второй каталог мокапов рядом и не перемещай оригиналы в корень репозитория.

- Сохраняй исходные структуру, тексты, взаимодействия и оригинальные изображения. Не подменяй ресурсы похожими без согласования.
- Храни локально все необходимые ресурсы: изображения, шрифты, иконки, видео, стили и скрипты. Не добавляй CDN и hotlink-зависимости. Если файл не удаётся сохранить, укажи точный URL/путь и причину; браузер используй как запасной способ загрузки.
- Различай архив и Angular: `http://localhost:4320` — статический `public/legacy`, `http://localhost:4321` — Angular-каталог. Восстановленный HTML в архиве не означает, что лендинг восстановлен/перенесён в Angular; для этого должны существовать вариант в `src/app/landings`, маршрут и Angular-карточка.
- При изменении структуры проверяй все затронутые ссылки и пути: HTML `src`/`srcset`/`href`, CSS `url(...)`, favicon, шрифты, URL из JavaScript и ссылки каталога. Проверяй наличие файлов и фактический HTTP-ответ.
- Перед тем как сообщить, что мокап готов к просмотру, открой именно целевую ссылку в браузере. HTTP `200` недостаточно: проверь корректный `DOCTYPE`, отсутствие постороннего текста/диагностики в HTML, применившиеся стили (не голую разметку), локальные CSS/JS, фактическую загрузку фотографий и шрифтов, а также одно важное интерактивное действие. Рабочая главная или успешная сборка не доказывает, что целевая страница существует и отрисовалась правильно.
- При восстановлении из Git переноси точное содержимое файла, не используй усечённый вывод терминала как исходник. Сразу проверь начало HTML (`<!doctype html>`), размер/целостность файла, отсутствие строк вроде `Warning: truncated output`, затем пересобери Tailwind и проверь CSS в браузере.
- Не говори, что локализовал все ресурсы, если ещё остались удалённые шрифты/CDN/hotlink или не проверены локальные URL. Если точный ресурс не получается сохранить даже через браузер, перечисли его и причину; не оставляй внешнюю ссылку молча.
- Для просмотра архива используй `npm run mockups:legacy` (порт 4320), Angular-каталога — `npm run mockups` (порт 4321). Tailwind CSS архива собирай локально командой `npm run mockups:tailwind`, без CDN.
- Генерируй CSS только для реальных страниц входа; не сканируй архивные снимки и дубли.
- Доступные Angular-варианты регистрируй в `apps/mockups/src/app/mockups.ts`. Не добавляй в каталог ссылки на отсутствующие legacy-файлы.
- Legacy-мокап — исходник и справочный артефакт. Перенос в Angular выполняется отдельно и постепенно по правилам `shtorivdom-angular-mockup-porting`.
- Проектные скиллы и новые правила для Codex пиши на русском языке.

При обычной работе с мокапами не меняй `apps/shtorivdom-site`, не выполняй деплой и не удаляй архивные оригиналы.

# Ревью правки

Чек-лист для просмотра диффа — своего или чужого. Перенесён из DesignPad и
сокращён под сайт shtorivdom.

## 1. Объём

- Сделано ровно то, о чём просили. Попутный рефактор и «заодно причесал» —
  вырезать.
- Нет незапрошенных файлов: заметок, чейнджлогов, лишних `.md`.
- Изменённое рядом, но не по задаче, — вернуть как было и сказать словами.

## 2. Работает ли

- Цепочка пройдена целиком: кнопка → запрос → ответ → видимый след. Для форм
  заявки — письмо действительно пришло.
- Проверено в браузере (`npx nx serve shtorivdom-site`), а не только сборкой.
  Не смог проверить — сказать прямо.
- SSR: страница открывается прямой ссылкой и после перезагрузки, в консоли
  сервера нет ошибок про `window`/`document`.

## 3. Интерфейс

- Узкий экран (375px) проверен: ничего не вылезает, меню открывается.
- Есть отклик на действие: «заявка отправлена» по ответу сервера, а не сразу.
- Состояния читаются не только цветом; курсор на нажимаемом; у картинок `alt`.
- Тексты — по-русски, без опечаток и технических слов.

## 4. Код

- `any` нет. Модификаторы доступа расставлены, `readonly` на инжектированном.
- Нет дублирования: рядом уже есть компонент, директива или утилита.
- Комментарий объясняет «почему». Пересказ кода — убрать.
- Импорты не по абсолютным путям `apps/...`.

## 5. SEO

- Новая страница — в `tools/build-sitemap.mjs` (каталог подхватывается сам),
  карта пересобрана: `node tools/build-sitemap.mjs --check`.
- У страницы есть `title` и `description`.

## 6. Перед коммитом

- Изменённые файлы отформатированы Prettier.
- Сборка `npx nx build shtorivdom-site` проходит.
- Секретов и `.env` в диффе нет.

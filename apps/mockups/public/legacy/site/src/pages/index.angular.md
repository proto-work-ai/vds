# Главная `/`

Общие правила полей, иконок и состояний: `_common.angular.md`.

- Angular: `HomePage`.
- Блоки: hero, преимущества, каталог, CTA калькулятора/квиза, преимущества работы,
  этапы заказа, цены, работы, до/после, клиенты, отзывы, FAQ, нижняя заявка.
- Клиенты: отдельный `SiteClients`, вход `clients` с типизированным списком названий и
  локальных логотипов; все логотипы вписываются без искажений в одинаковые по высоте ячейки
  и всегда показываются в исходных цветах без CSS-фильтров.
- Hero-форма: имя*, телефон*, согласие; без комментария.
- Нижняя форма: телефон\*, комментарий, согласие.
- Поведение: кнопки и ссылки, свайп отзывов на mobile, FAQ с клавиатуры, состояния форм.
- Скролл: навигационные якоря плавно ведут к секциям с отступом под шапку; FAQ не
  перескакивает; свайп отзывов не прокручивает всю страницу по горизонтали.
- Иконки hero-формы: имя — `@tui.user`, телефон — `@tui.phone`, золотые 20px внутри поля.
- Сверка: порядок блоков, тексты, изображения, desktop/mobile, focus/error/loading/success.

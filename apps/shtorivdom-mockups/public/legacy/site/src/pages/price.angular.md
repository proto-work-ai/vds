# Цены `/price/`

Общие правила скролла, полей, иконок и состояний: `_common.angular.md`.

- Angular: `PricePage`.
- Блоки: внутренний hero, цены по разделам, вкладки прайса, пояснение, нижняя форма.
- Цены берутся из `price-list.service.ts`; пометка об ориентировочных ценах сохраняется.
- Вкладки управляются Angular-состоянием и доступны с клавиатуры.
- Форма: телефон\*, комментарий, согласие.
- Скролл: смена вкладки сохраняет позицию; широкая таблица скроллится только внутри контейнера.
- Иконка формы: телефон — `@tui.phone`, золотая 20px внутри поля.
- Сверка: все вкладки, цены, mobile overflow и состояния формы.

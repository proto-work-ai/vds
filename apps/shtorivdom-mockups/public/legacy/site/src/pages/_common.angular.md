# Общая механика страниц и форм

Этот файл дополняет описание каждой страницы. Локальный `page.angular.md` имеет приоритет,
если для конкретной страницы указано иное поведение.

Описание ведётся как техническое задание на перенос мокапа в Angular. Для каждого
интерактивного блока указываются будущий компонент, его состояние, события, формы и
источники данных. Макетные обработчики из `site.js` служат описанием поведения и после
переноса заменяются Angular-логикой; копировать их в приложение нельзя.

Базовый размер обычного текста — `14px`. Более крупный размер задаётся явно только
заголовкам, акцентам и компонентам, где это предусмотрено макетом.
Размеры текста в пикселях используются только чётные: `12px`, `14px`, `16px`,
`18px` и далее.

Перенос выполняется с минимальными визуальными и поведенческими изменениями. Иконки в
HTML-мокапе берутся из установленного `@taiga-ui/icons`; в описании фиксируется то же
имя `@tui.*`, которое будет использовано в Angular.

Повторяемые настройки при переносе сразу выносятся в единый типизированный источник
Angular. Цены, контакты, сроки и другие общие значения нельзя копировать в несколько
шаблонов; макет и Angular должны получать их из общей конфигурации или генератора.

## Скролл и навигация

- Переход по якорю выполняется плавно с отступом под фиксированную шапку.
- После Angular-навигации новая страница начинается сверху, кроме явно указанного якоря.
- Раскрытие FAQ, смена вкладки и шагов не должны неожиданно переносить пользователя.
- После сброса длинного сценария страница прокручивается к началу его блока.
- Горизонтальный overflow страницы запрещён; горизонтальная прокрутка разрешается только
  внутри явно описанного слайдера или таблицы.

## Формы

- Имя, если показано: обязательное, `tuiInput`, иконка `@tui.user`, звёздочка `*`.
- Город, если показан: обязательный, `tuiInput`, иконка `@tui.map-pin`, звёздочка `*`.
- Телефон: обязательный, `tuiInputPhone`, иконка `@tui.phone`, звёздочка `*`, `*appDefer`.
- Комментарий: необязательный `tuiTextarea`, без иконки, если локальное описание не говорит иное.
- Согласие: обязательный `tuiCheckbox`, ссылка открывает страницу согласия.
- Иконки полей: золотые `#c9a84c`, визуальный размер `20px`, находятся внутри поля.
- Ошибки показываются рамкой и значком внутри поля; отдельный список ошибок не выводится.
- Во время отправки повторная отправка заблокирована. Ошибка API остаётся под формой.
- После успеха форма скрывается и показывается блок «Спасибо!».

## Визуальная и функциональная проверка

- Desktop и mobile, первый экран и нижняя часть страницы.
- Tab-порядок, focus, hover, пустая отправка, частично заполненная форма, API error и success.
- Соответствие текстов, изображений, цвета, размера, отступов, порядка блоков и иконок.

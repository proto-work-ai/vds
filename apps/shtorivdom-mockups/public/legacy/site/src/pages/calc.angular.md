# Калькулятор `/calc/`

Общие правила полей, иконок и состояний: `_common.angular.md`.

- Angular: `CalcPage` и `CalcComponent`.
- Шаги: вид штор, размеры, коэффициент сборки, карниз, результат, отправка расчёта.
- Расчёт выполняется Angular-состоянием без ручной DOM-логики.
- Форма результата: имя*, телефон*, согласие; расчёт передаётся скрытым описанием.
- Иконки формы: имя — `@tui.user`, телефон — `@tui.phone`, золотые 20px внутри поля.
- Скролл: ошибки размеров не меняют позицию страницы; после расчёта результат и форма
  остаются в текущем контексте; переход по ссылке на калькулятор учитывает шапку.
- Сверка: каждый вид, границы размеров, коэффициенты, карниз, итог, mobile и отправка.

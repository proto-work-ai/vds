# Taiga UI MCP

В проекте используется Taiga UI. Конфигурация и локальная документация:

- `config/taiga-ui-mcp.json` — конфигурация MCP;
- `config/taiga-ui.config.ts` — настройки Taiga UI;
- `docs/TAIGA-UI-MCP.md` — инструкция по подключению;
- `examples/TAIGA-UI-EXAMPLE.component.ts` — пример компонента.
